Onboarding Flow — How it works

  • P1.S1 Splash — Full black screen, gold RIKSA logo with Khmer "រ", bilingual tagline. "Get Started" pill at bottom. Language toggle in corner. No API call — pure static.
  • P1.S2 Province Selector — 2x3 grid of province cards with crest icon, English + Khmer name, tagline. Selected card gets gold border + checkmark. Continue button disabled until one is picked. State held in app, sent with register. No API call yet.
  • P1.S3 Topic Selection — 3 vertical cards (STEM, Technology, History) with icon + lesson count. Multi-select — tap to toggle checkmark circle. Topics map to category memberships AFTER registration (Phase 4 categories). No API call at this step.
  • P1.S4 Register — Mini logo, form: Full Name, Email, Password, Province (readonly from S2 with "Change" link). Gold "Create Account" button. Google OAuth option below divider. Language toggle at bottom. POST /api/v1/auth/register with {fullName, email, password, provinceId}.
  • P1.S12 Profile Setup — Avatar picker (preset for now — no upload endpoint), Display Name, Bio textarea with 160 char counter, Gender segmented selector, Province dropdown. GET /api/v1/auth/me to load, PUT /api/v1/auth/me to save.

Flow sequence: Splash → Province → Topics → Register (lands on Home) → later, Profile Setup via Edit Profile from Home or Profile screen. The first 3 screens are pre-registration state collection. Province is required at register time; topics persist post-registration via category join.
